# Visuell egenkontroll – V3

Dato: 20. september 2026. Vurderingen gjelder de ferdige Blender-eksportene og integrasjonen på desktop/mobil.

| Kriterium        | Vurdering                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------ |
| Modellkonsistens | Uendret frysergeometri, mål, kurver og studiolys; kontrollert mot V2.                                  |
| Komposisjon      | Helt lokk og bunn innenfor alle utsnitt. Samme kamera i scene 2/3, rolig tettere sluttvinkel.          |
| Metafor          | Lyse former blir identifiserbare gjennom farge og navn uten å flytte innholdet.                        |
| Emballasje       | Taperte, avrundede transparente bokser med lokk og klips; brødet beholder klar pose.                   |
| Typografi        | Store mørke spørsmålstegn uten kort. Lette varenavn og prioriteringstekst med fine forbindelseslinjer. |
| Klistremerke     | Samme fysiske plassering øverst til høyre på fronten i alle 73 vinkler. Diskret 12 × 14 cm.            |
| Teknisk          | Avsluttende modell- og bildevalidering, 29 enhetstester og 66 nettleserkontroller bestått.             |

**Samlet egenvurdering: 8,5/10.** Dette er en subjektiv designvurdering, ikke en automatisert kvalitetsscore. Uttrykket er rolig og sammenhengende, og metaforen leses tydeligere enn i V2. Mat og plast er fortsatt stiliserte produktvisualiseringer. Klistremerkets små tekster er detaljer på avstand, ikke ment som lesbar grensesnitttekst eller skannbar QR i nettbildet. `sticker.png` viser selve grafikken i full oppløsning.

QR-grafikken peker til prosjektets offentlige rotadresse. Det er ingen implementert QR-/innloggingsfunksjon. Fysisk mobil- og trykkprøve gjenstår før eventuell publisering/produksjon. Brukeren godkjente V3 og den etterfølgende annotasjonsrevisjonen 20. september 2026 som én lokal baseline med språkendringene. Se `docs/qa.md` i prosjektroten for avsluttende QA og det åpne restpunktet for smal mobil kombinert med 200 % tekst.
